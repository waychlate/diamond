# DIAMOND walkthrough (study notes)

Written from a tutoring session. Meant for rereading before explaining the model to someone.
Config values are from `config/agent/default.yaml` and `config/trainer.yaml` (highway-env: 5 actions, 3x48x320 frames).

## 1. What the model does (30-second version)
A learned video game. Input: the last **4 frames + their 4 actions**. Output: the **next frame**.
The frame is generated by **diffusion**: start from pure noise, denoise it in 3 steps, conditioned on the history.
A separate small model predicts reward/end. An RL agent trains inside this imagined game.

## 2. Imagined-game loop (`src/envs/world_model_env.py`)
- `obs_buffer` = rolling 4-frame history, `act_buffer` = 4 actions, one row per parallel game (32 games = one batch).
- `step(act)`: write action into last slot -> `sampler.sample(...)` generates next frame -> predict rew/end ->
  `roll(-1)` both buffers (oldest frame dropped) and put the new frame in the last slot.
- Generated frames become context for later ones, so errors compound (drift) over long rollouts.
- Parallel games share one UNet call per denoising step (batched); they don't add calls.
- `reset_dead` re-seeds only the finished rows from real data.

## 3. The three EDM components -> code
| Component | Question it answers | Code |
|---|---|---|
| Training | Which noise levels, what target? | `Denoiser.forward`, `setup_training`, `apply_noise` (`denoiser.py`) |
| Preconditioning | How to scale net input/output at every sigma? | `compute_conditioners`, `compute_model_output`, `wrap_model_output` |
| Sampling | How to turn the denoiser into a generator? | `DiffusionSampler.sample`, `build_sigmas` (`diffusion_sampler.py`) |

### Training (one sample)
1. Real clean next frame `y`, plus 4 clean context frames (context is **not** noised) and 4 actions.
2. `sigma` ~ log-normal per sample: `exp(randn*1.2 - 0.4)`, clipped to [0.002, 20] (median ~0.67).
3. `noisy = y + sigma*randn` (+ small offset noise). sigma is the **std of the noise**.
4. UNet gets `c_in*noisy`, context, actions, `c_noise`.
5. Loss = MSE against `target = (y - c_skip*noisy) / c_out` (a rearranged clean frame, not the raw image).
- Why log-normal: noise matters multiplicatively; uniform would spend nearly all samples at high sigma.
  Too-high `loc` -> low-sigma (final detail) undertrained -> blurry/grainy outputs.

### Preconditioning: `D(x) = c_skip*x + c_out*F(c_in*x, c_noise)`
Goal of all four: keep what the UNet sees and outputs at roughly unit size at every sigma.
- `c_in = 1/sqrt(sigma^2 + sigma_data^2)`: scales the noisy input (big at high sigma -> small c_in).
- `c_skip = sigma_data^2/(sigma^2 + sigma_data^2)`: how much noisy input to copy straight to the output.
  ~1 at low sigma, ~0 at high sigma. **This is NOT the UNet skip connection.**
- `c_out = sigma*sqrt(c_skip)`: scales the net output to the size of the correction needed. Small at low sigma
  (a residual), levels off at sigma_data=0.5 at high sigma (net produces the whole image).
- `c_noise = ln(sigma)/4`: just the noise level, fed to `noise_emb`. Not a multiplier.
- `sigma_data = 0.5` = std of clean images. Variances add: `std(noisy)^2 = std(clean)^2 + sigma^2`.
- Repo twist: sigma is first replaced by `sqrt(sigma^2 + 0.3^2)` (offset noise), so the effective sigma never goes tiny.
- Verified numerically (scratchpad script): `c_in*x` and `target` stay ~0.5-1.0 across sigma 0.002..20.

### Sampling (config: 3 steps, Euler, no churn)
- `build_sigmas`: even spacing in the rho-th-root space (rho=7), then raised to the 7th power -> ~[5, 0.28, 0.002, 0].
  Dense at low sigma, sparse at high.
- Loop: `denoised = D(x, sigma)`; `d = (x - denoised)/sigma`; `x += d*(next_sigma - sigma)`. Last step lands exactly on `denoised`.
- Why several steps: a single step from pure noise returns the **average of all plausible frames** (blurry). Each step commits further.
- Start `x = randn` is a blank canvas, **not** the starting frame (that's in `prev_obs`). Randomness -> different plausible futures.
- Fixed during the loop: `prev_obs`, `prev_act`. Changing: `x`, `sigma`.
- Sampler starts at sigma 5, not 20: training rarely draws sigma > 5 (~5%), >20 (~0.2%), and at sigma 5 the image is already ~10x buried
  (signal std 0.5 vs noise 5), so extra range adds nothing.
- Heun (`order: 2`): trial step, measure slope again at the landing point, average the two slopes. 2x network calls; Euler used here.
- Churn (`s_churn>0`, gamma): temporarily re-add noise to raise sigma to `sigma*(1+gamma)`. Off here.
- Open observation (unverified): initial `x = randn` has std 1, but the first call is told sigma=5 (training inputs at sigma 5 had std ~5).

## 4. The UNet (`src/models/blocks.py`, `inner_model.py`)
- Input: 4 context frames stacked **along channels** (4x3=12) concatenated with the noisy next frame (3) = 15 channels, `conv_in` -> 64.
- Encoder: `d_blocks` + stride-2 conv `Downsample` (48x320 -> 24x160 -> 12x80 -> 6x40, 64 channels everywhere).
- Bottleneck: `mid_blocks` (self-attention only here, since `attn_depths` are all 0). Shape 64x6x40.
- Decoder: `u_blocks` + nearest-neighbour `Upsample` + conv, back to 48x320, then `conv_out` -> 3 channels.
- **UNet skip connections**: encoder feature maps are concatenated into the decoder at each level, returning fine detail
  (lane lines, car edges) that the bottleneck compressed away.
- Conditioning vector: `cond = cond_proj(noise_emb(c_noise) + act_emb(act))`, length 256.
  - `noise_emb`: FourierFeatures (fixed random frequencies, cos/sin) of `c_noise`.
  - `act_emb`: Embedding(5, 64) per action, 4 actions flattened = 256. 256 must match because the two are added.
  - Every ResBlock's `AdaGroupNorm`: normalize, then `x*(1+scale)+shift`, with scale/shift per channel from `cond`.
- `conv_out` and each ResBlock's `conv2` start at zero weights.

## 6. Common mix-ups (from the quiz)
1. `c_skip` (shortcut around the whole net) vs UNet skip connections (encoder->decoder feature maps).
2. 5 -> 0.28 -> 0.002 is the **sampling** schedule; training draws a **random** sigma per sample.
3. The training target is `(clean - c_skip*noisy)/c_out`, not the raw clean image.
4. `x` in the sampler is a noise canvas, not the starting frame.
5. `cond_channels = 256` is about adding the noise and action vectors, unrelated to the 64 image channels.
6. `c_noise` is the noise-level input; it isn't added to `c_in`.
